# Brand

> Status: active. Configured for Aditya Chouhan / LinkedIn Funnel Architecture using the Claude Design System.

## Visual references

- Identity archetype: Technical Builder, Consultative Authority, Pipeline Architect.
- Palette inspiration: Claude Design System (Warm Terracotta, Charcoal Ink, Soft Clay, Warm Canvas Cream).

## Fonts

- Primary Body & Sans: `Inter`, `-apple-system`, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
- Editorial & Accents: `Newsreader`, `Georgia`, "Times New Roman", serif
- Monospace / Code: `JetBrains Mono`, `Fira Code`, monospace

## Colours

- `--canvas`: `#FAF7F2` (Claude warm canvas cream)
- `--ink`: `#1F1E1D` (Claude dark charcoal ink)
- `--ink-2`: `#736B63` (Claude warm muted secondary text)
- `--accent`: `#D97757` (Claude signature terracotta / coral)
- `--accent-soft`: `#F4E8DF` (Claude soft peach / light clay pill fill)
- `--border`: `#E3D8CE` (Claude warm card border)
- `--border-accent`: `#C97356` (Claude warm terracotta border)
- `--card-bg`: `#FEFEFC` / `#FFFFFF` (Claude white surface)
- `--slab`: `#FCFBF8` (Claude off-white slab)

## Layout and typography

- Diagrams follow a 12-column modular grid with generous whitespace, high-contrast hierarchical headers, and rounded pill containers (border-radius: 999px for pills, 16-24px for cards).
- All cards feature warm border outlines with subtle atmospheric drop shadows.
