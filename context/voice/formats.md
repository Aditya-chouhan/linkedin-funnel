# LinkedIn Post Formats (Claude + Apple Standard)

Four battle-tested formats designed to convert attention into qualified pipeline without algorithmic penalties.

| Format | When to Use It | Structure & Anatomy | Paired Visual Asset |
|---|---|---|---|
| **1. The Architecture Teardown** | Releasing or explaining a multi-step system or workflow | 1. Contrarian hook<br>2. Diagnosis of existing failure mode<br>3. 4–5 numbered system pillars<br>4. Deliverable summary<br>5. Keyword comment CTA | System Architecture Diagram (`linkedin-funnel.png` or `linkedin-funnel.gif`) |
| **2. The Content Waterfall Breakdown** | Content-to-pipeline repurposing or creator-led GTM | 1. The volume trap vs. anchor asset<br>2. The 1-video trunk mechanics<br>3. The 3 roots teardown<br>4. Multi-feed splintering rules<br>5. Blueprint download CTA | Waterfall System Graphic (`content-waterfall@2x.png` or `content-waterfall.gif`) |
| **3. The Proof / Benchmark Post** | Sharing quantifiable results, audit data, or client wins | 1. The baseline metric vs. outcome<br>2. What we changed (the single variable)<br>3. 3 operational lessons<br>4. Open-source recipe | Clean benchmark card / before-after split |
| **4. The Open-Source Release** | Open-sourcing a kit, CLI, prompt set, or schema | 1. Why we open-sourced this<br>2. What is inside the repository (5 items)<br>3. MIT license note<br>4. Velocity keyword CTA<br>5. Pinned comment with GitHub link | Clean repository banner with architecture preview |

## Universal Rules Across All Formats

- **No external links in body**: Link is always in the pinned first comment.
- **Velocity Comment Trigger**: Use a crisp single keyword (`FUNNEL`, `PLAYBOOK`, `CODE`, `BLUEPRINT`).
- **Semantic Tags**: Exactly 3 to 5 topic tags placed on the final line after a blank space.
